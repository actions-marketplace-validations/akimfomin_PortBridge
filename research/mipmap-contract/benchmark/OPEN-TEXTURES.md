# Vulkan replay with open textures

Three textures from the Khronos glTF examples add opaque, transparent and translucent pixels to the generated inputs. Build the [Vulkan replay](README.md#reproduce) with the same NVIDIA source, stock module and PortBridge rewrite. The runner accepts an unpadded file of exactly width × height × 4 RGBA8 bytes in the input argument. It clears all generated levels before each correctness readback. This keeps a missing store visible rather than retaining the previous variant's output. The clear is outside the GPU timing interval.

## Results on RTX 4070 Ti SUPER

The unmodified NVIDIA shader and PortBridge rewrite produced identical bytes on all three complete chains with fixed full Wave32. In an additional run we explicitly swapped the logical workgroup indices 1 and 4 in the NVIDIA shader and kept the physical subgroup numbering. This simulated a mapping permitted by Vulkan. The rewritten shader's output remained identical when rerun. No driver on the test bench supplied the swapped mapping by default.

| Open texture | Generated bytes, stock and rewrite match | Changed bytes in permuted NVIDIA result | Changed alpha bytes | Rewrite added, median of 35 timing pairs |
| --- | ---: | ---: | ---: | ---: |
| Fox opaque atlas, 1024² | 1,398,100 | 2,414 | 597 | 1.024 µs |
| AlphaBlendLabels, 1024² | 1,398,100 | 1,685 | 367 | 1.024 µs |
| Stained Glass Lamp grille, 2048² | 5,592,404 | 10,095 | 2,695 | 2.048 µs |
| Total | 8,388,604 | 14,194 | 3,659 | |

The comparison covers the stand-alone sRGBA8 shader, with no compositor, paint brush or alpha-coverage-preserving filter. GPU utilization was 50% and 49% immediately before and after the combined run. The run shows visible corruption under the simulated mapping and does not establish a speed gain. Hardware with Wave64 and real native lane reordering remain open. ## Reproduction

Use the commands below after the stock and rewrite builds from the benchmark README. Python needs Pillow for PNG decoding and NumPy for comparison. The script checks input file hashes and does not include the three images in this repository. Fox is CC0 by PixelMannen. AlphaBlendModeTest is CC BY 4.0 by Ed Mackey and Analytical Graphics. Stained Glass Lamp is CC BY 4.0 by Wayfair and Eric Chadwick. [Source and licenses](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models) · [Per-file licenses](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/REUSE.toml)

```powershell
python open_textures.py $Scratch --prepare-from "$Nvpro/nvpro_pyramid"
$Permuted = Join-Path $Scratch 'permuted'
glslang -V --target-env vulkan1.1 -o "$Permuted/fast.spv" "$Permuted/srgba8_mipmap_fast_pipeline.comp"
spirv-val --target-env vulkan1.1 "$Permuted/fast.spv"
Copy-Item -LiteralPath "$Stock/general.spv" -Destination "$Permuted/general.spv"
$Cases = @{ 'fox-atlas'=1024; 'alpha-labels'=1024; 'stained-glass'=2048 }
foreach ($Item in $Cases.GetEnumerator()) {
    $Side = $Item.Value
    $Name = $Item.Key
    $Out = Join-Path $Scratch "fixed-$Side-$Side-$Name"
    $Rows = & "$Scratch/mipmap.exe" $Stock $Side $Side '4070 Ti SUPER' "$Scratch/$Name.rgba" 35 $Out "$Rewrite/fast.spv"
    if ($LASTEXITCODE) { throw 'Stock and rewrite comparison failed' }
    $Rows | Set-Content -LiteralPath "$Out/timings.csv" -Encoding ascii
    $Out = "$Out-permuted"
    $Rows = & "$Scratch/mipmap.exe" $Permuted $Side $Side '4070 Ti SUPER' "$Scratch/$Name.rgba" 4 $Out "$Rewrite/fast.spv"
    if ($LASTEXITCODE) { throw 'Permuted negative control failed' }
    $Rows | Set-Content -LiteralPath "$Out/timings.csv" -Encoding ascii
}
python open_textures.py $Scratch
```
