# Первый публичный пилот M0–M4

План готов к отдельному решению владельца. Пилот проверяет одну задачу на Xbox Series и одну на PS5. Результаты не закрывают автоматически требования предыдущих этапов.

## Допуск

1. Передать независимому рецензенту архив, контрольную сумму и два патча. Повторить чистые тесты. Сверить выборку ролей и историй M4 со ссылками. Независимо повторить контроль SEARCH-08 и RAD-07.
2. Сохранить SHA публичного main, последний одобренный артефакт Pages и проверенный SQLite checkpoint. Зафиксировать переменные публикации, успешный GitHub Pages deploy и отдельно состояние Cloudflare.

## Проверочная ветка

1. После разрешения владельца опубликовать только указанную ветку. Вручную запустить `pages.yml` на её SHA. Ветка выполняет тесты, формирует `portbridge-review-site` на три дня. Публичные GitHub Pages и Cloudflare защищены условием main.
2. Проверить скачанный артефакт на мобильной и настольной ширине. Сверить Search, Radar, People, Lab, Impact, manifest, ссылки, видимые роли и хеши. Проверить удаление отозванного отчёта и старой версии файла скрытого профиля.
3. После отдельного разрешения дать изолированный адрес preview согласившимся участникам. Для Xbox предложить сравнение времени жизни ресурса. Для PS5 — синтетическую проверку границы подгруппы. Записать, помогла ли находка выбрать проверку. Согласие на задачу не распространяется на публикацию отчёта или повторные сообщения.

## Публичная инфраструктура и откат

Основной адрес меняется отдельным решением после проверки ветки. Сверить ручной и плановый запуск GitHub Actions, GitHub Pages, Cloudflare при его использовании, поколение связанных файлов, очередь Lab и прежний размер каталога. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

Если сломан manifest, неверна атрибуция, появились неожиданные отправки или пропала очередь, остановить пилот. Владелец отключает выпуск соответствующим флагом и возвращает одобренный артефакт и совместимую резервную копию. Git-откат через revert сохраняет историю. Если прежний артефакт снова показывает скрытый профиль, пересобрать последний проверенный код с действующей политикой. После отката проверить обе платформы, очередь, ссылки и значения счётчиков.
