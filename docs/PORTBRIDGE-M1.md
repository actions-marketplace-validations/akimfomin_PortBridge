- Сбор хранит попытку, успех, возраст, проверенные страницы и причину сбоя по каналу. Для связанных публичных обсуждений, ревью и файлов PR есть ограниченный сбор метаданных. Сырые тела и патчи в новый индекс не сохраняются. Форки и ссылки остаются кандидатами до ревью. ## Операционные наблюдения

В запуске #146 сборка и выкладка GitHub Pages успешны, проверка публичных данных остановилась через минуту. При последующей сверке обе контрольные суммы site/lab совпали с ожидаемыми #146 и у обычного адреса, и у адреса с ключом поколения. Это устанавливает позднюю сходимость наблюдаемого снимка. Пограничная причина первоначального сбоя отдельно не доказана. У запуска #129 и #146 разница 5 ч 51 мин при заданном интервале 30 мин. Порог по успешным данным — два часа, он не обещает доставку запланированных запусков. [Запуск #146](https://github.com/akimfomin/PortBridge/actions/runs/45761703311) · [Расписание GitHub](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

GitHub Actions сохраняет существующий облачный сбор, ограниченные права и офлайн-режим. Кэш может быть удалён, поэтому отдельно хранится контрольная копия с ограниченным сроком. Cloudflare Pages Free допускает 500 сборок в месяц, а две сборки в час потребовали бы около 1 440 за 30 дней. Cloudflare Workers Cron — возможный сигнал для отдельного runner, если есть согласованный приёмник и пересмотр бюджета. Замена runner или платная инфраструктура в M1 не включены. [GitHub cache](https://docs.github.com/en/actions/reference/workflows-and-actions/dependency-caching) · [Cloudflare Pages limits](https://developers.cloudflare.com/pages/platform/limits/) · [Workers limits](https://developers.cloudflare.com/workers/platform/limits/)
