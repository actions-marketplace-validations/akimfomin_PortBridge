# PortBridge Discovery · дополнение к Master Spec V3

Дополнение утверждено владельцем при предварительной приёмке M1. Исходная [Master Spec V3](PORTBRIDGE-SPEC.md) сохраняет силу со всеми 116 требованиями. Шесть ID ниже обязательны, общий реестр содержит 122 требования.

- **DISC-01 · Внешняя техническая база.** Изучить shadPS4, Xenia, VKD3D-Proton, DXVK, Mesa/RADV/ACO, LLVM AMDGPU, Wine, RPCS3, Vulkan Memory Allocator, D3D12 Memory Allocator, Microsoft DirectXShaderCompiler, SPIRV-Tools, AMD GPUOpen и найденные релевантные источники.
- **DISC-02 · Исторические реализации.** Связывать техническую суть актуальной проблемы с внешней работой по инструкциям GPU, алгоритмам, функциям, архитектурным механизмам, коду, истории, закрытым Issues и старым PR.
- **DISC-03 · Применимость.** Для каждого кандидата показать точный первоисточник и ревизию, прежнюю проблему, сходство, принципиальные отличия, ограничения, лицензию, вариант адаптации и проверочный тест. Кандидат остаётся предложением до независимой проверки.
- **DISC-04 · Связи.** Discovery входит в Search. Radar получает кандидатов и передаёт перспективные в Lab. People учитывает публичный технический вклад с правилами приватности. Impact учитывает подтверждённое переиспользование. Отдельный экран со списком репозиториев не требуется.
- **DISC-05 · Практическая проверка.** Исследовать не менее десяти актуальных задач разных команд. Сохранить кандидатов, отрицательные результаты, сравнение с обычным GitHub Search и независимый набор с ложными совпадениями. Ограничить объём, приоритеты и запросы, использовать кэш.
- **DISC-06 · Приёмка.** Реестр хранит все предыдущие ID и DISC-01–06. M2 включает поисковую основу и проверку концепции. Полная работа Radar, Lab, People и Impact относится к их этапам. Завершение M2 требует рабочего кода, сравнения, реальных примеров и пакета аудита. Шесть черновиков сохраняются локально. M3 начинается после приёмки.

M1 предварительно принят по отчёту. Его независимая проверка и публичная эксплуатационная приёмка остаются открытыми. Внешние публикации и отправки подчиняются §2 Master Spec V3.
