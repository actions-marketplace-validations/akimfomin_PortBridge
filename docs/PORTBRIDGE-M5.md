# M5 · Network, Agents и кандидат пилота

M4 предварительно принят владельцем. В M5 подготовлены двуязычный вход Start, добровольный цикл Lab через MCP, подписка с локальным курсором и партнёрская лента с JSON, API и виджетом. Сайт, CLI, HTTP и MCP читают одну модель. Отдельная локальная команда Network подкрепляет предложения актуальной задачей, ролью и первоисточником. [Инструкция](PORTBRIDGE-M5-START.md) · [План пилота](PORTBRIDGE-M5-PILOT.md) · [Реестр 122 требований](PORTBRIDGE-CHECKLIST.md)

## Проверка People и Impact

Детерминированная выборка из снимка M4 включила 55 уникальных профилей и 87 проверок утверждений о роли или связи. Использованы 91 уникальный источник, включая источники специализаций. У 82 проверок подтвердился публичный автор или владелец. Четыре исторических ссылки Zettrox сейчас недоступны. Одно расхождение найдено и исправлено. Профили с выраженной ролью в выборке включали 7 владельцев или сопровождающих, 8 ревьюеров, 8 аппаратных тестировщиков, 9 межпроектных участников, 18 разработчиков и одного исторического автора. Шесть ранее размеченных связей Xbox–PS5 проверены отдельно, некоторые категории пересекаются.

- **CoDrift → CDR-0000.** Точная запись PR и числовой ID GitHub корректируют авторство этого PR. Коррекция ограничена ролью автора. Источник не устанавливает тождество аккаунтов. Специализацию «CPU», ранее выведенную из отрицательного упоминания в заголовке, у этой записи заменили на графику и память. [PR](https://github.com/fxceless/victory-fork/pull/265) · [GitHub API](https://api.github.com/repos/fxceless/victory-fork/pulls/265)
- **Четыре активных пары.** По источникам прослеживаются технические связи boykopovar, JamesCicada, PrivacyOnion и throny. Это атрибуция работы в проектах. Принятие одного и того же кода отдельной командой требует собственного доказательства. [AnyBox](https://github.com/boykopovar/AnyBox) · [AnyPS5](https://github.com/boykopovar/AnyPS5) · [Victory #472](https://github.com/fxceless/victory-fork/pull/472) · [XCL #880](https://github.com/xcl-dev/xcl/pull/880)
- **Две особые пары.** Связь nordicov с Xbox хранится как историческая, поскольку указанный Zettrox #63 недоступен. Для InoriRus есть PS4 и PS5, условие Xbox–PS5 больше не выполняется. [Zettrox #63](https://github.com/Zettrox/ztrx/pull/63) · [KytyPS5](https://github.com/KytyPS5/KytyPS5)
- **Предел качества.** Владение сверялось по метаданным, ревью по первичной записи, аппаратная роль по конкретному отчёту. Специализация в профиле остаётся выводом из технического контекста. Локальный тест opt-out скрывает переименованную учётную запись и её прежнюю атрибуцию, исключает профиль из новой выдачи и убирает прежний файл снимка. Удалённый публичный кэш проверяется при пилоте. [Тесты People](../tests/test_community.py) · [Исправление M5](../tests/test_m5.py)

## Три сквозные проверки

В каждом сценарии новый публичный PR попал в Search и инкрементальный Discovery. Автоматический запуск вернул по пять исследовательских ссылок. Для Lab три пары отобрали вручную и проверили на точных ревизиях. Ни одна из них не появилась в собственной первой пятёрке автоматического Discovery (0 из 3). [Сверка ссылок](../audit/evidence/historical-m5-pairs.json) Два изолированных клиента MCP в разных каталогах с отдельными ключами обменивались состоянием только через локальный сервис. Отчёт сначала оставался на ревью. После отдельного решения были доступны атрибуция и результат. Повторная отправка с тем же ключом запроса вернула прежний ID. Отзыв XCL убрал результат из Impact и дал событие исчезновения в подписке. Повтор без GitHub сохранил полный локальный цикл на записанных источниках.

| Задача | Что показала проверка | Следующий полезный тест |
| --- | --- | --- |
| [XCL #2775](https://github.com/xcl-dev/xcl/pull/2775) ↔ [AnyXboxX #354](https://github.com/LooperSalty/AnyXboxX/pull/354) | Чтение закреплённых исходников отклонило гипотезу об одинаковом условии освобождения ресурса. У XCL тестовый карантин по нескольким очередям, у AnyXboxX отдельный путь вытеснения LRU. | Две перестановки сигналов очередей и отрицательный контроль: запрещено переиспользовать плитку после первого сигнала. |
| [Continued #2365](https://github.com/ubiquitarianism/leonida/pull/2365) ↔ [AnyPS5 #20730](https://github.com/boykopovar/AnyPS5/pull/20730) | Гипотеза об одинаковом состоянии отклонена. Continued различает предельное значение ожидания и неподанную работу, AnyPS5 меняет ожидание в другой очереди. | Три случая завершения: поданный tick, ошибка отправки, sentinel. |
| [KytyPS5 #2038](https://github.com/KytyPS5/KytyPS5/pull/2038) ↔ [Vulkan](https://github.com/KhronosGroup/Vulkan-Docs/blob/d4e43a045c9aaaaee930bf6d0ca404a3ee389ba8/appendices/VK_EXT_pipeline_robustness.adoc) | Подтверждено сходство на уровне проверки наличия функции. Поведение шейдера на конкретном драйвере остаётся открытым. | Синтетический буфер на устройстве с расширением и отдельный прогон резервного пути. |

Результаты этих трёх новых испытаний получены на уровне исходников. GPU, игры и внешние добровольцы в испытаниях M5 не участвовали. Существующие подтверждённые примеры использования AnyXboxX и FrameLab относятся к прежним публичным событиям. [AnyXboxX](https://github.com/LooperSalty/AnyXboxX/pull/133#issuecomment-7136721736) · [FrameLab](https://github.com/5headsmartbtw/leonida-framelab/issues/15#issuecomment-7160148587)

## Network и эксплуатация

Семи группам назначены отдельные фильтры. В локальном плане содержатся источники роли, нужда проекта и предложение одного следующего шага. Количество исследуемых связей не ограничено числом выбранных пилотов. Подбор внутренний, разрешение на отправку хранится отдельно. История учитывает оставленный без ответа PortWatch, отказ PC Race и действующие размещения Awesome и Six on PC. Ссылки на утёкшие данные не входят в интеграции. [Журнал](COMMUNITY-COORDINATION.md) · [Формат ленты](../API.md#лента-для-партнёров)

Повторное использование подтвердилось для FrameLab на двух задачах в разные дни. Для AnyXboxX подтверждено применение по одной задаче, для Continued — в двух PR в один день. Историческое подтверждение по NET-12 — **1 из 3**, FrameLab. Независимых применений версии M5 внешней командой зафиксировано **0**. Звёзды, размещения и повторы одного испытания не участвуют в подсчёте. Три новые возможности для пилота готовы к отдельному согласованию. [FrameLab #12](https://github.com/5headsmartbtw/leonida-framelab/commit/d1da938ecf7b4e3d3faf40e5046907ba48986125) · [FrameLab #15](https://github.com/5headsmartbtw/leonida-framelab/issues/15#issuecomment-7160148587) · [Continued #1042](https://github.com/ubiquitarianism/leonida/pull/1042#issuecomment-7140737395) · [Continued #1284](https://github.com/ubiquitarianism/leonida/pull/1284#issuecomment-7145516624)
