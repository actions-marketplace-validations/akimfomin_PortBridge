# ADR 014 · ограниченный поиск исторических работ

Состояние · реализовано в локальном кандидате M2.

Одинаковый симптом может возникать на разных API, компиляторах и поколениях GPU. Для сравнения нужны первоисточник, его ревизия и различия архитектур.

- Проверенный корпус хранит исходники, спецификации, диагностику и обсуждения с исходными состояниями. Запись требует ревизии, лицензии, границ применимости и теста. Рабочий снимок ограничен 128 записями. CLI и локальный API читают встроенную копию. Сайт, Action и MCP в публичном режиме используют версионированный экспорт. Preflight обозначает возврат к встроенной копии, когда внешний снимок недоступен.
- Технические слова, символы и смысловые группы ранжируют результаты. Проверенные пары поддерживают поиск по URL известных задач. Локальный patch-ID и общий предок Git дают отдельные факты о двух diff. Применимость проверяется в принимающей архитектуре.
- Результаты входят в существующий каталог. CI формирует информационную сводку с ограниченным вводом и временем выполнения. Для будущего Radar сохраняются стабильный ID, источник, ревизия, авторство и предлагаемый тест. Очередь и события вклада относятся к поздним этапам.

Гибрид выбран по замороженной выборке. Он повысил полноту с 80% до 97,5% и дал пять явных ложных совпадений вместо трёх. FTS5 сохранил полноту, но дал 13 ложных совпадений. Вариант SVD требует библиотеку и дал 15 ложных совпадений. [Измерения](../PORTBRIDGE-M2.md#сравнение-качества-поиска)

Откат возможен к локальной базе `a203e1f` в отдельном рабочем дереве или через обратные коммиты M2. Схема SQLite и прежние публичные маршруты совместимы.
