# ADR 016 · доказательства People и Impact

Локальный кандидат M4, 26 ноября 2026 года.

People использует идентификаторы и ссылки существующего каталога. Дополнительный сбор охватывает комментарии, ревью выбранных PR, владельцев и авторов Discovery. Он использует публичный GET, лимит, условное чтение и ротацию. Текст обсуждений, почта и непубличные данные не копируются в новый слой. Исчезнувший источник получает статус. Успешное полное получение небольшого потока ревью обновляет его состав.

ID GitHub переживает переименование. Для записей без ID остаётся нормализованный публичный логин. Неоднозначность не объединяется. Владелец, автор, ревьюер и техническая специализация имеют отдельные основания. Граф хранит дату, тип, ссылку и причину. Список браузера использует сокращённый снимок, подробный профиль открывается отдельно. API, CLI и MCP читают тот же набор данных.

Impact строится из проверенных квитанций принимающих проектов и признанных отчётов Lab. Событие, вклад и принятие считаются отдельно. Дедупликация использует канонический URL с сохранённым ID комментария и тип вклада. Локальный участник Lab остаётся проверяемой ролью в журнале. Публичный GitHub-логин ему автоматически не присваивается.

## Исправление и согласие

Сопровождающий проверяет личность по публичному аккаунту GitHub, первоисточнику и просьбе самого участника, затем применяет локальное решение `python -m portbridge.community_policy --decision decision.json`. Формат включает `action`, `proof`, `at` в UTC, для действий с профилем также `actor.login` и `actor.user_id`. Для `correct` и `withdraw` нужен `source`. Доступность задаётся `opt-in` с `scope` и `until` в пределах 90 дней. Действия `hide`, `restore` и `opt-out` применяются идемпотентно.

Текущая проекция исключает скрытый профиль и лишние подписи. Следующая сборка удаляет прежние версии файлов из выходной папки. Дополнительный сбор People исключает скрытый ID и очищает его записи из собственного кэша. Первичный код сохраняет исходную атрибуцию. При публикации нужно отдельно учитывать внешние кэши и старые артефакты. [Форма](https://github.com/akimfomin/PortBridge/issues/new?template=people.yml)

`opt-out` hides the profile, removes availability and excludes future People collection. Use `withdraw-availability` to remove only the volunteer preference while retaining a visible profile.
