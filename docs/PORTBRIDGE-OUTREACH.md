# Сотрудничество PortBridge / PortBridge collaboration

Команда выбирает один поиск по PR, одну проверку или один способ получать данные. Ревью, решения и код остаются у команды. Использовать журнал [проверенных взаимодействий](COMMUNITY-COORDINATION.md), [пилот](PILOT.md) и [памятку участнику](QUICKSTART.md). Публичный [канал сопровождения](https://github.com/akimfomin/PortBridge/issues/91) остаётся открытым.

| Что проверять | Источник |
| --- | --- |
| Независимый тест, принятие исправления, повторное использование | Первичный отчёт, решение сопровождающего либо коммит принимающего проекта. Сверять задачу, автора, ревизию, время и доступное подтверждение роли. |
| Написанное предложение и полученный ответ | Публичная ссылка и дата. Повторить обращение можно при появлении новых данных по той же задаче с учётом ответа и правил площадки. |
| Упоминания в каталогах | Awesome и Six on PC внесли PortBridge. PC Race отказался по своему редакционному правилу. PortWatch VI #55 остаётся без публичного ответа по сверке M0. [История и ссылки](COMMUNITY-COORDINATION.md#передача-сообществу-26-ноября-2026--final-community-handover) |
| Использование интеграций | Пилоты Action для XCL и Continued выполнялись в PortBridge. Внешние установки Action/MCP и число активных пользователей неизвестны. [Журнал](COMMUNITY-COORDINATION.md#участие-и-использование--participation-and-use) |

Локальный журнал и индивидуальные черновики хранятся в игнорируемой Git папке `.portbridge/m0/`. Для каждой карточки сверять состояние обсуждения, возможный отказ, роль и текущий SHA перед внешним обращением. Владелец разрешил адресные пилотные обращения. Подключение в стороннем репозитории решает его владелец. Фиксировать основание, отправку, ответы и следующий допустимый шаг. После пилота спросить, помог ли результат выбрать проверку и вернулась ли команда к инструменту на другой задаче. Один запуск, проверка исправления и повторная работа с самим инструментом учитываются отдельно.

Публичная статистика отражает подтверждённые действия. Число внешних установок, скачиваний и сэкономленное время остаются неизвестными без отдельного свидетельства. PortBridge не ставит трекеры и не считает чтение ленты повторным использованием.

## English

Offer one concrete prior-work check, an existing Lab task or a small read-only integration. Receiving teams retain control of their repositories and review process. Use primary links and record attribution, decisions and repeated use. The project owner authorized relevant individual pilot invitations. Check the latest discussion before writing. The receiving owner decides whether to install the integration. Practical starting points are the [quick start](QUICKSTART.md), [Test Lab](TEST-LAB.md) and [one-PR workflow](GITHUB-ACTION.md).
