**Developer decision.** Give the fixture an explicit expected console value of 30. Select Ukrainian in the receiving launcher, save and reload, assert that the stored integer is 30 and the selected label is Ukrainian, then assert that `LocaleName(30)` returns `uk-UA`. Using the external menu position as the expected integer would introduce an off-by-one error. The external PS4 launcher corroborates the author-cited label/ID convention across an actual save/load path. This supports the fixture design. A PS5 platform specification or independent PS5 execution would be needed to establish the underlying PS5 contract. The locale string comes from the receiving change. The check compared pinned source tables and save/load paths. Execution of either launcher, console behavior, catalog availability and downstream adoption remain unverified.

## Where the hint was lost

1. Feeding the hash-matched public description and frozen title to M5.2's normalizer reproduced empty terms, cues, signals, references and external repositories. The repository extractor recognizes certain GitHub URLs. The bare launcher name stayed in prose, outside the controlled vocabulary. The subject selector returned an empty string and the recorded URL run stopped before transport. 2. A nonempty subject would still face two limits. The M5.2 target list includes the shadPS4 emulator core. The Qt launcher has a separate repository. The bounded request searches issue and PR text, while this evidence is in a source file. There are no discarded ranks to regrade on this case. A generic Ukrainian translation, the origin's own fix and an unrelated platform's numeric identifier all fail the frozen independence or boundary test. **Bounded improvement to evaluate.** Recognize an exact, unambiguous repository name from a reviewed public source registry, subject to word boundaries and the existing input cap. A verified canonical repository name in the same clause as a mapping or implementation claim can be shown as an author-supplied lead. Keep at most one such lead and retain only its canonical repository ID. An allowlisted, pinned code excerpt or reviewer-verified source link would provide technical evidence. A bare mention, a translation catalog, an ambiguous short name or an unrelated number must earn no decision credit. A repository absent from the reviewed registry remains unresolved by this route. This proposes a general capability. It supplies no new holdout result or measurement of coverage.
