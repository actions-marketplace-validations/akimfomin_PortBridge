## Reproduce from the checkout

Run the offline regression suite from the repository root.

```sh
python -B -m unittest discover -s tests -p test_lab_reports.py -v
```

For a fresh public import, run this Python snippet from the repository root. It reads the public result discussion anonymously. Only the local ignored `.portbridge` directory receives a database and site export. Results can change if the upstream thread changes.

```python
import json
from pathlib import Path
from portbridge.catalog import Catalog, ReadOnlyCatalog
from portbridge.export import export
from portbridge.lab import TASKS
from portbridge.lab_reports import FRAMELAB_TASK, refresh_reports
from portbridge.mcp import PortBridgeMCP

root = Path(".portbridge/m51-lab-check")
catalog = Catalog(root / "lab.sqlite3", "portbridge/data/seed.json")
task = next(t for t in TASKS if t["id"] == FRAMELAB_TASK)
sync = refresh_reports(catalog, [task])[FRAMELAB_TASK]
assert sync["state"] == "fresh", sync["state"]
site = export(catalog, root / "site")
rows = json.loads((site / "data/lab.json").read_bytes())["tasks"]
card = next(t for t in rows if t["id"] == FRAMELAB_TASK)
mcp = PortBridgeMCP(ReadOnlyCatalog(catalog.path))
result = mcp.run_tool({"name": "portbridge_lab", "arguments": {"task": FRAMELAB_TASK}})
assert result["structuredContent"]["tasks"] == [card]
print(sync["checked_at"], card["status"], card["coverage"], card["adoption"])
print([(r["url"], r["authority"], r["outcome"]) for r in sync["reports"]])
```

Run `python -m http.server 8766 --bind 127.0.0.1 --directory .portbridge/m51-lab-check/site`, then open [the local card](http://127.0.0.1:8766/?lang=en#/lab?task=framelab-12-vulkan-handoff). Use `?lang=ru` to inspect the Russian label.
