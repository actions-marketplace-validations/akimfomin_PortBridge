# PortBridge M5.2 — поиск по ссылке на PR

26 ноября 2026 года. Ветка для аудитора — [audit/review](https://github.com/akimfomin/PortBridge/tree/audit/review). Исходная версия — [M5.1, 0738093add1ed01dad89c4bdcb6df74eb8891701](https://github.com/akimfomin/PortBridge/blob/0738093add1ed01dad89c4bdcb6df74eb8891701/audit/LATEST.md). [Заранее зафиксированные условия оценки](https://github.com/akimfomin/PortBridge/blob/3eb002253d97095bb5909dc8f56721d159c3d362/audit/evidence/m52/intent.md) · [Реализация M5.2, e1c3f840df2ab4456b7348f4ce8b5b576ed474db](https://github.com/akimfomin/PortBridge/commit/e1c3f840df2ab4456b7348f4ce8b5b576ed474db).

Разработчик может передать обычную ссылку на публичный PR без подбора ключевых слов:

```sh
python -B -m portbridge.discovery_scan --online --url https://github.com/LooperSalty/AnyXboxX/pull/429
```

Ответ показывает тему, число поисковых запросов, использование кэша и до пяти ссылок. Если внешние источники не проверялись, результат объясняет причину. Поиск одного PR расходует до одного внешнего поискового запроса и отдельно читает метаданные PR. Плановый процесс сохраняет лимиты 64 входных записей, 5 поисковых запросов на пакет и одной страницы из 5 результатов на запрос. Сохранённые результаты доступны через CLI, MCP и снимок сайта.

## Что изменилось

| Проверка | M5.1 | M5.2 |
| --- | --- | --- |
| `vkQueueSubmit`, `CreateGraphicsPipelineState` | Символ распознавался в заголовке. Сигнал из описания сохранялся в нижнем регистре и отбрасывался при выборе темы. | Оба символа дают ту же тему в заголовке, описании и сохранённой записи v4. [Тесты](../tests/test_discovery_links.py) |
| Сохранённый снимок из 11 169 PR | Тема у 2 520 | Тема у 3 771. Ещё 1 251 запись получила тему, 0 потеряли её, 89 сменили прежнюю непустую тему. Во втором, отдельном снимке — 3 из 5 в обеих версиях. Это охват разбора. [Счётчики и два публичных примера](evidence/m52/saved-observations.json) |
| Обычная ссылка без результата | У незнакомой ссылки раздел Discovery мог отсутствовать | Видно, был ли распознан технический сигнал, запускался ли поиск, завершился ли он и доступен ли свежий ответ. При изменении ревизии старые совпадения перестают отображаться как текущие. [CLI и сайт](../tests/test_discovery_presentation.py) |
| Счётчик повторного использования | Общий итог включал исторический FrameLab | Исторический повтор — **1 команда из 3**, FrameLab. Для перезапуска M5 — **0 из 3** и **0** команд с первым подтверждённым применением. Старые записи и их повторный импорт не пополняют новый счётчик. Для свидетельства использования M5.2 в реестре закреплён коммит реализации, указанный выше. [CLI и правила зачёта](evidence/network.md) |

Если прежняя версия вообще не записала сигнал из описания, восстановить его только по этой строке базы невозможно. Обновлённый формат получает исходные данные при очередном чтении PR. Прежний ETag не блокирует такое обновление.

## Что дал поиск

Перед настройкой выбраны четыре новых PR из четырёх проектов. Для каждого зафиксирован вопрос разработчика, для одного — ожидаемая пустая выдача. В обе версии подали одинаковые входы. Метаданные PR и поисковые ответы учитывались отдельно. [Исходные условия](evidence/m52/intent.md) · [Все ссылки в порядке выдачи и решение по каждому PR](evidence/m52/assessment.md)

| PR | M5.1 | M5.2 |
| --- | --- | --- |
| [XCL #2852](https://github.com/xcl-dev/xcl/pull/2852) | Нет темы, 0 запросов, 0 ссылок | `command list`, 1 запрос, 5 ссылок. Правило очистки состояния при повторном использовании адреса осталось неизвестным. |
| [Continued #2392](https://github.com/ubiquitarianism/leonida/pull/2392) | Нет темы, 0 запросов, 0 ссылок | `vk_shader_stage_all`, 1 запрос, 5 ссылок. Совместимость ключей кэша предкомпилятора и рантайма остаётся проверить в проекте. |
| [KytyPS5 #2565](https://github.com/KytyPS5/KytyPS5/pull/2565) | Нет темы, 0 запросов, 0 ссылок | Нет темы, 0 запросов, 0 ссылок. Поиск не дал независимой проверки соответствия языка с ID 30. |
| [AnyPS5 #27600](https://github.com/boykopovar/AnyPS5/pull/27600), документация | Нет темы, 0 запросов, 0 ссылок | Нет темы, 0 запросов, 0 ссылок. Отрицательный контроль пройден. |

**Ни одна из десяти ссылок на новых PR не удовлетворила заранее заданным критериям.** Соответствующее требование SEARCH-08 остаётся открытым. Сохранены [выдача M5.1](evidence/m52/baseline.json), [выдача M5.2](evidence/m52/candidate.json) и [страницы ответов GitHub](evidence/m52/search-responses.json). Финальное сравнение воспроизвело ответы без сетевых запросов. Во время разработки и оценки GitHub получил четыре разных поисковых запроса, включая диагностику известного случая. При отдельном запуске обычного CLI с пустым кэшем GitHub исчерпал анонимную квоту чтения метаданных. CLI показал `rate_limit` и сделал 0 поисковых запросов.

**Известная регрессия AnyXboxX #429.** Проверены отдельно исходный открытый PR из M5.1 и текущее состояние после слияния. Для нового сравнения обе версии получили одни и те же метаданные слитого PR. M5.1 не извлёк ни одного из двух признаков. M5.2 извлёк `D3D12_TILE_RANGE_FLAG_NULL` и `UpdateTileMappings`. При одном запросе поиск по операции вернул пять ссылок. На третьем месте — тест переназначения тайлов, который разработчик может адаптировать для проверки своего аллокатора. Тест использует буфер и одну очередь. Безопасность повторного использования тайла текстурами между очередями остаётся открытой. Этот PR использовался при настройке правила выбора операции и оценён отдельно от четырёх новых. [Выдача и границы применимости](evidence/m52/assessment.md) · [Исходный тест vkd3d-proton](https://github.com/HansKristian-Work/vkd3d-proton/blob/d912baf6d70254b105036ba718bafaec3cdd7a35/tests/d3d12_sparse.c#L420-L497)
